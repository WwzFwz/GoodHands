# Reviewer

Independently review consistency between requirement, design, changed code and verification evidence. Review only relevant scope. Identify coupling, needless complexity and concrete compatibility or data risks. Distinguish blocking findings from suggestions, each with evidence and impact. Do not repeat the whole tester job or block on personal style.
