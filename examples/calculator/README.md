# Proyek uji calculator

`calculator.py` sengaja memiliki bug penjumlahan. Tiga test dalam `tests/` adalah kriteria penerimaan yang tidak boleh diubah Coder. Ini proyek contoh, bukan test suite harness.

Dari root GoodHands, jalankan `goodhands init --project examples/calculator --model MODEL_ID --runner local`, lalu sesuaikan model dan siapkan API key. Contoh task hasil `init` sudah sesuai dengan proyek ini. Jalankan dengan `goodhands run --project examples/calculator --allow-local-exec`.

Untuk demo tanpa API gunakan `goodhands demo`; perintah tersebut membuat proyek contoh terpisah sehingga folder ini tetap bisa digunakan untuk pengujian model sungguhan.
